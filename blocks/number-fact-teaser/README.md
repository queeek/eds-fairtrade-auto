# number-fact-teaser

Custom **columns** block. 

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: fact rows: a number paragraph and a fact text paragraph; one text row with bold eyebrow, h2, text and a CTA link.
