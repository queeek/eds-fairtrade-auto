# page-hero-carousel

Custom **carousel** block. 

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: mobile image (square), optional desktop image (wide), then heading (h1 on the first slide, h2 after), text and a CTA link.

## Supported variations

| Variation | Option class |
| --- | --- |
| Sky blue | `skyblue` |
| Night sky | `nightsky` |
