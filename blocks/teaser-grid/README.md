# teaser-grid

Custom **cards** block. 

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: image, optional date tag paragraph, h3 with bold pretitle and title, text paragraph, link paragraph (card link).

## Supported variations

| Variation | Option class |
| --- | --- |
| Small (3-up) | `small` |
| Listing (Load more) | `listing` |
