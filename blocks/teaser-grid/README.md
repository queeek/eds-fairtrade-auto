# teaser-grid

Custom **cards** block. 

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: image, optional date tag paragraph, h3 with bold pretitle and title, text paragraph, link paragraph (card link) — or a row holding only a link to a page on this site, filled from that page (page-lead image, date and h1, Tags metadata as pretitle, first body paragraph).

## Supported variations

| Variation | Option class |
| --- | --- |
| Small (3-up) | `small` |
| Listing (Load more) | `listing` |
