## C0 foundation

- **Runtime contract:** `stardust/runtime-contract.json` — vanilla EDS, `.block` + `<name>-wrapper`, buttons formatted-only (`p.button-wrapper > a.button.primary|secondary|accent`), empty sections collapse (`main .section:empty { display: none }`).
- **Foundation source:** `styles/styles.css` lifts `stardust/prototypes/canon.css` (tokens, base reset, `.page-grid` container, shared primitives) verbatim in value, renamed to kebab-case for stylelint. Class map: `Button`→`btn`, `Icon`→`ft-icon` (EDS keeps `.icon` for `:name:` icons), `Image`→`ft-image`, `Footer`→`ft-footer` (avoids the `.footer` block class), `Richtext`→`richtext`, `Tag`→`tag`, `Wave`→`wave`, `Input`→`input`, `TopbarMainNavigation`→`main-nav`, `TopbarSearch`→`search-panel`; every other `Foo--barBaz--qux` → `foo-bar-baz-qux`. Module units reuse `.page-grid`, `.btn.variant-*.color-*`, `.ft-icon`, `.ft-image.<ratio>`, `.richtext`, `.tag`, `.wave` instead of redefining them. Icons: sprite `/icons/ft-icons.svg#<name>` (canon `assets/icons.svg`).
- **Section scaffold:** sections add no box (`main > .section { margin: 0 }`); blocks own their grids and full-bleed grounds (container cap 1920 lives in `.page-grid`, not on `main`, so grounds stay full-bleed beyond 1920). Default content sits in a capped, padded `.default-content-wrapper`. Section styles (section-metadata `style`, one value): `theme-skyblue`, `theme-leafgreen`, `theme-nightsky` (white text), `theme-grey`, `theme-white`, `theme-dark` (white text) — grounds only.
- **Buttons:** authored `<strong><a>` = skyblue pill (canon `variant-primary color-skyblue`), `<em><a>` = skyblue outline (`variant-secondary`), `<em><strong><a>` = leafgreen pill (accent). Blocks that need other canon variants apply `.btn` classes to the moved anchor's wrapper context. Edit-mode repaint (EW (a)/(b)) included.
- **Fonts:** self-hosted from the capture (OFL): Exo 2 variable (latin, latin-ext, italic) + Alegreya Sans 400/500/700/800/900 (+ latin-ext 700–900, italic 700–900) in `fonts/`, `@font-face` in `styles/fonts.css`; metric-matched `exo-2-fallback` / `alegreya-sans-fallback` (Arial, fontTools-computed) in `styles.css`. No font substitutions. Roboto removed. `head.html` gains only the favicon link (`/favicon.svg`, the site's own icon); boilerplate `favicon.ico` removed.
- **Chrome decode tier: template-slotted (#95).** `blocks/header` rebuilds the prototype Topbar DOM (logo, 4 click flyouts, search overlay, locale dialog with filter, meta menu, mobile drill-down drawer, hide-on-scroll-down / show-on-scroll-up, Escape + focus return, scroll lock) and slots the authored nav document into it; `blocks/footer` does the same for the footer (link columns, social icons by link host, newsletter button, locale button that opens the header dialog). Header reserves `--nav-height` = `--topbar-height` (72 / 104 ≥ 640) so the late chrome load shifts nothing.
- **Chrome documents rule (page units follow it):** the header/footer resolve their document as: page metadata `nav` / `footer` (if set) → otherwise `/<locale>/nav` and `/<locale>/footer` when the page's first path segment is a locale folder (`xx-yy`, e.g. `/us-en/...`, `/ch-fr`) → otherwise `/nav` and `/footer` (the global `/en` site). So `/en` uses `/nav` + `/footer`, every `/us-en/**` page uses `/us-en/nav` + `/us-en/footer`, `/ch-fr` uses `/ch-fr/nav` + `/ch-fr/footer` — no page metadata needed. The three locales' chrome text differs (nav, meta links, labels, footer columns, logo), so there are six documents, all `Robots: noindex`, text verbatim from the captures. `<html lang>` follows the same rule (`us-en` → `en-US`, `ch-fr` → `fr`, else `en`), set in `scripts.js`.
- **Nav document shape (positional sections):** 1 brand (logo image or `:fairtrade-international:` icon + home link whose text is the a11y label) · 2 main nav (nested list: top label > group link > item links) · 3 meta links · 4 locale dialog (title `<p>`, lead `<p>`, rest-of-world link, regions list) · 5 UI labels (`key: value` list, EW5 text-as-metadata). Footer: 1 link columns (`<p>` title + `<ul>`) · 2 social · 3 newsletter · 4 labels. Logos: us-en / ch-fr in DA media `media/chrome/`; en as icon `/icons/fairtrade-international.svg`.
- **Links:** in-scope pages are root-relative; everything else stays absolute to `https://www.fairtrade.net/...` (integration boundary). Header search submits to the source site's `/<locale>/search-results.html` (dynamics row chrome-search, interim).
- **Not carried:** canon's content fader (reveal-on-scroll) is not part of the foundation (no reveal-on-scroll in EDS foundation); module units may own it per block if a gate needs it.
- **Shell:** `content/drafts/foundation-shell.html` → preview only (`/drafts/foundation-shell`), never published live.
- **Header fixes vs the prototype (found by chrome-compare on the preview shell):** single-group flyouts (Products) carry `has-single-group` (full-width group, 3-column list — lifted from the source clientlib); the drawer drops the prototype's `overflow: hidden` on `.mobile-menu` (it clipped every drill-down level to nothing; the source has none).
- **Header-open hook:** while any header panel is open (flyout, search, locale, meta menu, drawer) `body.header-open` is set and the document scroll is locked. The source fades the hero carousel controls (opacity/visibility 200 ms) while a header panel is open — the hero unit owns that rule (`body.header-open <hero controls> { opacity: 0; visibility: hidden }`, `transition: opacity .2s ease-in-out, visibility .2s ease-in-out`).
- **chrome-compare (preview shell, profile replica):** 1 residual — `motion@1440 Search [click]`: the source's first opacity transition on search open is the hero carousel controls (200 ms), absent on the hero-less shell; the header's own search panel matches (300 ms). Expected to clear when re-run on `/en` once the hero unit ships the hook rule. Warnings only otherwise (budget truncation, locale link pairing by name).
