# Design (descriptive — what the site is)

## Colour
Sky blue #0fc0fc is the primary (buttons, hero bands); lime #d4ff47 the secondary (page-lead bands, outline buttons); eggplant #7b1dab for links and accents; navy #001b6e for footer and article hero bands; near-black #1e1e1e text on white.

## Type
Headings in Alegreya Sans, weights 800–900, ramp 72 / 64 / 48 / 40 / 32 / 24 / 20. Body and UI in Exo 2 (variable), 18px / 1.6, 17px small text. Both self-hosted OFL faces.

## Shape and motif
12px radius on image cards; 100px pill buttons; organic blob "bubbles" for number facts; wave dividers between sections; soft shadow rgba(30,30,30,.1) 0 4px 8px on teaser cards.

## Components
Header (Topbar: logo, main nav with desktop flyouts, search, locale selector, meta menu), hero carousel, page lead band, breadcrumbs, text/image split, number-fact teaser, teaser grid (news cards), CTA section, accordion section, single image, iframe section, product teaser carousel, navy footer with link lists, social links and newsletter.
